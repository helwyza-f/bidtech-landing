# Services Templates

Template website untuk menampilkan layanan/produk bisnis dengan detail dan pricing.

## Fitur Umum

- Services listing dengan grid/card layout
- Service detail pages
- Feature highlights
- Pricing plans/tables
- Call-to-action buttons
- Client testimonials
- FAQ section

## Template yang Tersedia

- **Template 1**: Service cards dengan pricing
- **Template 2**: Detailed service pages
- **Template 3**: Tiered pricing layout

---
Tambahkan template Anda di folder ini dan update list di atas.
