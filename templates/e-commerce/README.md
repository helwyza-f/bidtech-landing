# E-Commerce Templates

Template website untuk toko online dengan product listing, cart, dan checkout system.

## Fitur Umum

- Product listing/catalog
- Product detail pages
- Shopping cart
- Checkout process
- Product filters (kategori, harga, rating)
- Search functionality
- User reviews/ratings
- Payment integration
- Order tracking

## Template yang Tersedia

- **Template 1**: Modern e-commerce platform
- **Template 2**: Minimalist shop design
- **Template 3**: B2B marketplace style
