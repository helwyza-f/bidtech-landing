# Event Templates

Template website untuk acara seperti seminar, konferensi, launching, dan undangan digital.

## Fitur Umum

- Event detail (tanggal, lokasi, waktu)
- Speaker/pembicara profile
- Agenda/schedule
- Ticket booking/registrasi
- Pembayaran tiket
- Live streaming section
- Venue map
- Photo gallery

## Jenis Event

- **Seminar** - Topik, pembicara, registrasi
- **Konferensi** - Agenda lengkap, networking
- **Launching** - Countdown, reveal produk
- **Undangan Digital** - E-invite, RSVP
