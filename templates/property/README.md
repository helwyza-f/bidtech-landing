# Property Templates

Template website untuk real estate seperti perumahan, kos, apartemen, dan agen properti.

## Fitur Umum

- Listing properti dengan foto/virtual tour
- Spesifikasi detail (luas, harga, lokasi)
- Map lokasi dan neighborhood info
- Filter pencarian
- Mortgage calculator
- Agent contact info
- Testimonial pembeli
- Gallery/portfolio

## Jenis Property

- **Perumahan** - Cluster, kavling residensial
- **Kos/Apartemen** - Unit harian/bulanan
- **Agen Properti** - Portfolio lengkap, listing
- **Commercial** - Ruko, office space, mall
