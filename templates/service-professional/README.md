# Service / Professional Templates

Template website untuk layanan profesional seperti konsultan, legal, akuntan, dan arsitek.

## Fitur Umum

- Profil dan keahlian
- Service/layanan detail
- Case studies/portofolio
- Pricing/rate
- Team profile
- Blog/insights
- Contact dan appointment booking
- Testimonial klien

## Jenis Profesional

- **Konsultan** - Business, marketing, IT
- **Legal** - Hukum, notaris, advokat
- **Akuntan** - Pajak, audit, keuangan
- **Arsitek** - Design, kontrak, supervisi
- **Dokter/Medis** - Praktik, appointment
