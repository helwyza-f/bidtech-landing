# Nonprofit / Donation Templates

Template website untuk yayasan, program sosial, dan platform donasi.

## Fitur Umum

- Profil yayasan/program sosial
- Program detail dan dampak
- Donasi online
- Volunteer registration
- Impact report/cerita sukses
- Team dan struktur organisasi
- News/blog update
- Contact dan sosial media

## Jenis Nonprofit

- **Yayasan** - Program sosial, laporan tahunan
- **Donasi** - Campaign donasi, tracking dana
- **Program Sosial** - Bantuan, pendidikan
- **Volunteer** - Bergabung tim, aktivitas
