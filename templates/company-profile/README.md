# Company Profile Templates

Template website untuk profil perusahaan yang menampilkan identitas, nilai, dan tim.

## Fitur Umum

- Hero section dengan tagline perusahaan
- About section (visi, misi, nilai)
- Team showcase
- Company statistics/achievements
- Contact information
- Footer

## Template yang Tersedia

- **Template 1**: Modern corporate style
- **Template 2**: Minimalist clean design
- **Template 3**: Dark theme professional

---
Tambahkan template Anda di folder ini dan update list di atas.
