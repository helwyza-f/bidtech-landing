# Automotive Templates

Template website untuk bisnis otomotif seperti dealer, rental, showroom, dan bengkel.

## Fitur Umum

- Katalog kendaraan
- Spesifikasi detail kendaraan
- Harga/financing options
- Test drive booking
- Service appointment
- Inventory management
- Customer reviews
- Contact dan lokasi showroom

## Jenis Automotive

- **Dealer** - Mobil baru, trade-in
- **Rental** - Booking kendaraan, harga
- **Showroom** - Display mobil, test drive
- **Bengkel** - Service list, appointment
