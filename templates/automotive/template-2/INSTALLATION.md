# Panduan Instalasi (Template-2 Otomotif)

## Prasyarat
- Node.js versi 18+ (Disarankan LTS terbaru)
- npm / yarn / pnpm

## Langkah Menjalankan Proyek

1. **Buka terminal dan arahkan ke folder proyek:**
   ```bash
   cd templates/automotive/template-2
   ```

2. **Instal seluruh dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan (development server):**
   ```bash
   npm run dev
   ```

4. **Buka aplikasi di browser:**
   Akses `http://localhost:3000` (atau port lain yang ditampilkan di terminal).

## Perintah Tambahan
- **Build untuk Produksi:**
  ```bash
  npm run build
  ```
  Ini akan mengompilasi aplikasi menjadi build siap produksi yang sudah dioptimalkan.
- **Menjalankan versi Produksi secara lokal:**
  ```bash
  npm start
  ```
