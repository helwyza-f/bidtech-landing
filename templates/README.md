## 📁 Struktur Setiap Template

Setiap template kategori akan berisi:
```
kategori/
├── template-1/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   ├── images/
│   └── README.md
├── template-2/
│   ├── ... (struktur yang sama)
└── README.md (info kategori dan fitur)
```

## 🚀 Panduan Menggunakan Template

1. **Pilih Kategori** - Tentukan jenis bisnis klien Anda
2. **Explore Template** - Lihat README di folder kategori untuk deskripsi fitur
3. **Use as Reference** - Gunakan sebagai inspirasi atau starting point
4. **Customize** - Sesuaikan dengan brand dan kebutuhan spesifik klien

## 💡 Tips Menambah Template

Untuk setiap template baru yang Anda buat:
- Buat folder dengan nama deskriptif (misal: `template-modern`, `template-minimal`)
- Sertakan file `README.md` dengan penjelasan fitur dan highlights
- Pastikan semua aset (CSS, JS, images) terorganisir dengan baik
- Update list di README kategori untuk mencatat template baru
