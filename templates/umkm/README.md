# UMKM Templates

Template website untuk usaha mikro, kecil, dan menengah seperti laundry, barbershop, salon, bengkel, dan toko bunga.

## Fitur Umum

- Informasi bisnis dan jam operasional
- Gallery/portfolio layanan
- Pricing/tarif
- Booking/appointment system
- Contact dan lokasi
- Testimoni pelanggan
- Social media integration
- WhatsApp contact button

## Jenis UMKM

- **Laundry** - Paket cuci, harga, pengiriman
- **Barbershop** - Jenis potong rambut, booking
- **Salon** - Layanan kecantikan, harga
- **Bengkel** - Jenis perbaikan, sparepart
- **Toko Bunga** - Katalog bunga, custom order
