# Portfolio Templates

Template website untuk showcase portfolio, project, dan case studies.

## Fitur Umum

- Project showcase dengan grid/masonry layout
- Project detail pages
- Filter/kategori project
- Case studies
- Client logos
- Before-after comparisons
- Skills/expertise showcase

## Template yang Tersedia

- **Template 1**: Grid portfolio layout
- **Template 2**: Masonry gallery view
- **Template 3**: Case study focused
