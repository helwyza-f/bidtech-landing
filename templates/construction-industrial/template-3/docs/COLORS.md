# Palet Warna: Construction & Industrial Template-2

Warna pada Template-2 dipilih secara cermat untuk mencerminkan ketegasan, kekuatan rekayasa, dan standar keselamatan industri berat.

| Nama Warna | Kode Hex | Kegunaan |
|---|---|---|
| **Safety Orange** | `#ea580c` / `#f97316` | Aksen tombol utama, status aktif, highlight judul |
| **Industrial Yellow** | `#f59e0b` / `#eab308` | Aksen sekunder, badge promo, rating bintang |
| **Dark Charcoal** | `#0f172a` / `#090d16` | Background bar mitra, kartu spesifikasi gelap, footer |
| **Slate Gray** | `#334155` / `#64748b` | Teks paragraf, ikon teknis, garis orbit |
| **Clean Surface** | `#ffffff` | Latar belakang kartu dan container konten |
| **Subtle Background** | `#f8fafc` / `#f1f5f9` | Kontras latar belakang section selang-seling |
| **Emerald Green** | `#10b981` | Status unit tersedia, sertifikasi resmi |
