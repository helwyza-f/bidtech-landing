# Construction / Industrial Templates

Template website untuk konstruksi dan industri seperti kontraktor, manufaktur, dan supplier.

## Fitur Umum

- Portfolio/project showcase
- Layanan/produk listing
- Spesifikasi teknis
- Sertifikasi dan penghargaan
- Team/expertise
- Equipment/machinery gallery
- Testimonial klien B2B
- Request quote form

## Jenis Construction/Industrial

- **Kontraktor** - Proyek konstruksi, portfolio
- **Manufaktur** - Produksi, kapasitas, quality
- **Supplier** - Bahan baku, harga, stok
- **Teknisi** - Maintenance, spare parts, support
