# Education Templates

Template website untuk institusi pendidikan seperti sekolah, kursus, bootcamp, dan platform webinar.

## Fitur Umum

- Informasi sekolah/kursus
- Program/kelas listing
- Jadwal pembelajaran
- Guru/instruktur profile
- Enrollment/pendaftaran
- Student testimonial
- Exam/sertifikat info
- Contact dan fasilitas

## Jenis Pendidikan

- **Sekolah** - Profil, program, berita
- **Kursus** - Daftar kursus, harga, instruktur
- **Bootcamp** - Program intensif, alumni success
- **Webinar** - Jadwal webinar, registrasi
