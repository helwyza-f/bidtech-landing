# Travel & Hospitality Templates

Template website untuk travel dan hospitality seperti hotel, villa, tour & travel, dan rental kendaraan.

## Fitur Umum

- Room/paket listing dengan gallery
- Booking system
- Harga dan availability
- Map lokasi
- Fasilitas detail
- Review/rating tamu
- Payment gateway
- Customer service chat

## Jenis Travel & Hospitality

- **Hotel** - Room types, booking, tarif
- **Villa** - Paket villa, fasilitas
- **Tour & Travel** - Paket wisata, itinerary
- **Rental Kendaraan** - Mobil, motor, bike
