# Landing Page Templates

Template website untuk landing page dengan focus pada conversion dan user engagement.

## Fitur Umum

- Hero section dengan strong CTA
- Value proposition section
- Features/benefits showcase
- Social proof (testimonials, stats)
- Pricing section (optional)
- FAQ section
- Newsletter signup
- Footer dengan CTAs

## Template yang Tersedia

- **Template 1**: SaaS landing page
- **Template 2**: Product launch landing page
- **Template 3**: Lead generation focused
