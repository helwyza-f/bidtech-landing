# Beauty & Wellness Templates

Template website untuk beauty dan wellness seperti skincare, spa, gym, fitness, dan salon.

## Fitur Umum

- Service/treatment listing
- Harga dan durasi
- Staff/therapist profile
- Appointment booking
- Product showcase (untuk retail)
- Before-after gallery
- Customer testimonial
- Promo dan membership packages

## Jenis Beauty & Wellness

- **Skincare** - Produk, konsultasi, perawatan
- **Spa** - Treatment, harga, paket
- **Gym/Fitness** - Membership, class schedule
- **Salon** - Hair, makeup, beauty services
- **Wellness** - Yoga, meditation, health
