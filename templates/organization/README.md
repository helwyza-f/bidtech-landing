# Organization Templates

Template website untuk organisasi seperti komunitas, organisasi sosial, dan perkumpulan.

## Fitur Umum

- Profil organisasi (visi, misi)
- Anggota/member directory
- Event/aktivitas listing
- Forum/diskusi
- Gallery kegiatan
- Membership registration
- Contact information
- News/blog update

## Jenis Organisasi

- **Komunitas** - Member network, event gathering
- **Organisasi Sosial** - Program sosial, donasi
- **Perkumpulan** - Alumni, hobby community
- **NGO** - Program dampak, laporan
